Designed and deployed the backend of VoltBuddy, a smart-home electricity bill tracking application, using AWS ECS Fargate, Docker, Amazon ECR, and an Application Load Balancer.

Implemented a GitHub Actions CI/CD workflow to build Docker images, push versioned images to Amazon ECR, update the ECS task definition, deploy the application, and verify backend health.

Deployed the frontend on Vercel and integrated it with the AWS-hosted backend. Configured CORS to support production authentication flows and verified that user registration and login work successfully.

<b>Technologies:<b/> AWS ECS Fargate, Amazon ECR, Docker, GitHub Actions, AWS IAM, Application Load Balancer, Node.js, Express, MongoDB Atlas, Next.js, Vercel.
